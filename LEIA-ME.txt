CADASTRO DE USUARIOS - Next.js 15 + TypeScript + CSS puro + JSON Server

COMO RODAR (2 terminais abertos na pasta do projeto)
1. npm install                (so na primeira vez)
2. Terminal 1:  npm run api   -> API em http://localhost:3001
3. Terminal 2:  npm run dev   -> site em http://localhost:3000
4. Login: aluno@unialfa.com / 123456
